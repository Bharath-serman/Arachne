# 3D Spider-Man Models

Place your rigged Spider-Man model here as `spiderman.glb`.

### Expected Skeletal Animations in GLB:
- `Idle` (default starting pose)
- `Crouch` (section 01 / about)
- `WebSling` (section 02 / projects)
- `SuperheroLanding` (section 03 / contact)

If this file is absent, the application gracefully renders a built-in articulated superhero rig with responsive materials and pose transitions.
