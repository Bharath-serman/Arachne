## ✦ Core Features

| Feature | Description |
|:---|:---|
| **CRT Environment** | 3D SpiderWebs forming the main visual world |
| **Camera Movement** | Scroll-controlled cinematic camera choreography |
| **Parallax** | Depth-based movement and spatial interaction |
| **VHS Effects** | Scanlines, distortion, noise and chromatic aberration |
| **Typography** | Large editorial titles with motion-based transitions |
| **Case Studies** | Projects presented through cinematic Spider displays |
| **Mouse Interaction** | Subtle camera and lighting response |
| **Smooth Scroll** | Inertia-driven scrolling and velocity-based spider animation |
| **Responsive** | Optimized experience for smaller screens |
